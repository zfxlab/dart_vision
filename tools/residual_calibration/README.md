# 绿灯残差标定工具

本地网页工具，用于人工记录计算值和实测参考值、比较残差补偿模型、独立验证和导出报告。不依赖 ROS，也不修改运行中的节点或串口指令。

## 启动

在项目根目录执行（本机工具依赖已经安装）：

```bash
bash tools/residual_calibration/run.sh
```

浏览器访问 **http://127.0.0.1:8501**。终端 `Ctrl+C` 停止。首次体验可在侧栏展开“打开项目 / 导入数据”，点击“载入演示数据”，然后“执行拟合”。演示数据为合成数据，不能用于实机补偿。

更换端口：

```bash
bash tools/residual_calibration/run.sh --server.port=8502
```

工具与项目共用根目录的 `.venv`（Python 3.12），依赖统一维护在根目录 `requirements-uv.in` / `requirements-uv.lock`。
新环境在项目根目录安装；已有 `.venv` 时只需执行安装命令：

```bash
uv venv .venv --python python3.12
uv pip install --python .venv/bin/python -r requirements-uv.lock
```

也可使用 Python 自带 venv 创建根目录 `.venv`，再用 pip 安装 `requirements-uv.lock`。
启动脚本根据自身位置定位项目环境，因此不需要手动激活环境。

## 现场记录约定

- 坐标系为 `stereo_camera_center_link`，距离为其原点到绿灯中心的空间直线距离。
- 表格中的距离单位是米，角度单位是度，向右为正。
- 计算角必须是**未加入 `dart_offset_rad` 的几何角**，计算值不得已经应用残差补偿。当前 `/aim_command` 包含补偿，不能不加区分地直接抄录为几何角。
- 一个测量位置的一次采集对应一行，建议记录有效帧均值、帧数和标准差。
- 用不同编号标识重复采集。验证集按位置或采集批次保留，不要将同一位置的相邻帧随机拆分。
- 距离、角度可以分别填写；某项缺少计算值或参考值时，该行不参与该项拟合。
- 标准差只作记录，第一版各测量点等权拟合，不自动按帧数或标准差加权。

CSV 英文列名：

| 列名 | 含义 |
|---|---|
| sample_id | 唯一测量点编号 |
| session | 采集批次 |
| split | train 拟合、validation 验证、excluded 排除 |
| distance_calc_m / distance_ref_m | 计算 / 实测距离 |
| yaw_calc_deg / yaw_ref_deg | 计算 / 实测几何角 |
| sample_count | 可选，采集帧数 |
| distance_std_m / yaw_std_deg | 可选，计算值标准差 |
| notes | 备注或排除原因 |

CSV 支持 UTF-8 和 UTF-8 BOM。示例在 [examples/measurements.csv](examples/measurements.csv)。

## 使用步骤

1. 新建项目，直接在表格输入；或者导入 CSV / 已保存的项目 JSON。
2. 填写项目名称，将记录设为拟合、验证或排除。
3. 为距离和角度分别选择模型，点击“执行拟合”。
4. 查看公式、补偿前后误差、映射图、交叉变量残差和独立验证指标。
5. 点击散点或选择编号查看原始记录；可以填写原因并改变记录用途。数据或模型变动后，旧结果失效，需重新拟合。
6. 用单点试算检查模型。超出训练输入范围时，保留原值而不外推。
7. 点击“生成导出文件”，下载 YAML 或完整结果 ZIP。

“比较所有候选模型”提供训练和验证指标，但不会自动选择模型。没有验证记录时明确显示“尚未独立验证”。有验证记录只表示计算了留出集指标，不意味着自动通过精度验收。

## 模型和边界

模型均表示完整映射 `corrected = f(raw)`，**不要再加一次原始值**：

- 不补偿：`y = x`。
- 常量修正：`y = x + b`。
- 线性修正：`y = c0 + c1*x`。
- 二次修正：`y = c0 + c1*x + c2*x*x`，仅距离支持。

常量、线性、二次分别至少需要 2、3、4 个完整训练点。线性和二次还需要足够多的不同输入值；病态分布拒绝拟合。距离映射在拟合范围内必须为正且单调递增。

角度差使用最短角差，输出归一化到 `[-180°, 180°)`。过于分散且没有明确方向的角度残差拒绝拟合。第一版为一维模型，不能补偿速度、温度、回差等未作为输入的条件。

训练范围之外的记录在图表、试算、导出修正表和误差统计中均**保留原始值**，与导出策略一致；不会依据验证点扩大范围。训练覆盖范围也不等于精度保证。

## 保存与恢复

- 编辑后自动保存当前项目到工具的 `.local_data/`，该目录不进入 Git。
- 刷新或重启后，从侧栏“本地草稿”恢复。新建空白项目不会覆盖已有项目。
- “保存项目 JSON”下载可携带的记录和模型设置；“导出测量 CSV”便于表格软件编辑。
- 打开外部项目或恢复草稿会创建新的本地副本，保留原稿。恢复后重新拟合，避免沿用旧计算结果。
- JSON 保留完整记录，包括未填完整的行和排除项。图表和模型只使用对应有效记录。
- 自动保存发生在单元格编辑提交后；编辑单元格后按 Enter 或点击其他位置提交。

可通过环境变量 `DART_CALIBRATION_DATA_DIR` 指定草稿目录。适用于本机单用户分析；同一项目在多个浏览器页签中编辑时应分别保存项目文件。

## 导出内容与 C++ 接入边界

```text
calibration_result.zip
├── project.json
├── measurements.csv
├── corrected.csv
├── compensation.yaml
├── report.html
├── plots/distance.png
├── plots/yaw.png
└── README.txt
```

HTML 报告内嵌 Plotly，可离线打开。PNG 为独立图片，轴标签使用英文以避免系统中文字体缺失；网页及报告主体为中文。仅成功拟合的维度生成相应文件。

YAML 记录模型版本、坐标系、原始记录指纹、训练范围、指标和系数：

- `coefficients` 按常数项到最高次项排列。
- 距离输入输出为 m，角度输入输出统一为 rad；导出时已换算系数。
- 角度完整映射后还需归一化到 `[-pi, pi)`，再按系统约定叠加 `dart_offset_rad`。
- 模型默认 `enabled: false`，范围外策略为 `use_raw`。
- 指标单位单独标注为 m 或 °，不能与角度模型的 rad 单位混淆。
- 当前工具只生成模型，**现有 `dart_aiming` 尚未实现该 YAML 格式的加载**。不要把它当作可直接生效的 ROS 参数文件。接入时应在 TF 转到 launcher_frame 后、时域滤波和飞镖补偿之前应用。

## 代码结构

- `app.py`：中文网页、草稿管理、图表选择和下载。
- `fitting.py`：数据校验、拟合、角度环绕、独立验证和过期判断。
- `storage.py`：CSV / JSON、原子草稿保存、模型导出。
- `plotting.py`：交互图表、离线 HTML 报告、PNG 和 ZIP。
- `run.sh`：使用项目根目录 `.venv` 启动工具。
- `examples/`：示例测量数据。
